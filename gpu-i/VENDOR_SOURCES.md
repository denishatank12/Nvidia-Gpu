# Vendor sources for the measured GPU

The measured card is an NVIDIA GeForce RTX 5060 Ti. NVIDIA identifies the RTX 5060 Ti as a Blackwell GPU with fifth-generation Tensor Cores and GDDR7 memory. The exact capacity, driver, power limit, and UUID used in this experiment come from `system/nvidia_smi_5060.txt`, not from a generic specification page.

- NVIDIA GeForce RTX 5060 Family specifications: <https://www.nvidia.com/en-us/geforce/graphics-cards/50-series/rtx-5060-family/>
- NVIDIA RTX Blackwell architecture: <https://images.nvidia.com/aem-dam/Solutions/geforce/blackwell/nvidia-rtx-blackwell-gpu-architecture.pdf>

The final measured values and card identity are reported in `METRICS.md`, `RUN_LOG.txt`, and the UUID-labelled CSV files.
